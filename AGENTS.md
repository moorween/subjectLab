# subjectLab — инструкции для агентов

Библиотека PlatformIO для ESP32 (Arduino-ESP32 3.x / pioarduino, C++17):
`Subject`, `BehaviorSubject`, `SubFilters`, `CoreLoop`, `Action`, `Remote`, `Async`.

## Где правда об API

- `docs/API.md` — описание публичного API. Это контракт: проекты-потребители и их
  агенты опираются только на него и на заголовки.
- `src/*.h`, `src/Async.cpp` — код.
- `CHANGELOG.md` — что изменилось в каждой версии и что ломает совместимость.

Не полагайтесь на память или пересказы API: читайте эти файлы.

## Правила при изменениях

Любое изменение публичного API (класс, метод, поле, сигнатура, поведение) в том же
коммите сопровождается:

1. правкой `docs/API.md` (описание + пример, если неочевидно);
2. тестом в `examples/selftest/main.cpp` (новый `testXxx()` и вызов в `runAll()`);
3. записью в `CHANGELOG.md` в раздел `## [Unreleased]`; если меняется поведение
   существующего кода — в подраздел «Меняет поведение»;
4. обновлением таблицы тестов в `README.md`, если добавлен тест.

Внутренние детали (то, что публично только технически) — в `tools/docs_ignore.txt`
с причиной, а не молча.

## Проверка

```bash
python3 tools/check_docs.py   # документация и CHANGELOG соответствуют коду
pio run                       # собрать самотест для ESP32 (examples/selftest)
```

Обе команды выполняются в GitHub Actions на каждый push. Самотест на плате запускает
человек: Upload and Monitor, затем `r` и `l` в мониторе порта; итог — `ИТОГ: ВСЁ OK`.

## Выпуск версии

1. Перенести `## [Unreleased]` в `## [x.y.z] — дата`, добавить новый пустой `[Unreleased]`.
2. Поднять `version` в `library.json` (SemVer: несовместимое изменение — major,
   новое — minor, исправление — patch).
3. `python3 tools/check_docs.py` (проверит, что версия есть в CHANGELOG).
4. Коммит, тег `vX.Y.Z`, `git push && git push --tags`.

## Устройство и подводные камни

- `CoreLoop` привязан к задаче FreeRTOS, которая крутит `run()`. Межъядерная доставка —
  через `post()`: одно выделение памяти на сообщение, при переполнении очереди
  сообщение теряется (`dropped()`).
- Отложенные вызовы держат `Subject` из `shared_ptr` через `weak_ptr` (`guarded()`);
  глобальные объекты и поля класса вызываются напрямую.
- `Async` не потокобезопасен; удаление задач во время `tick()` откладывается до его конца.
- Колбэки `Subject` вызываются без внутреннего замка — из них можно подписываться,
  отписываться и вызывать `complete()`.
- Не вызывать из прерываний.
